3. **Implement K8s client wrapper (pod create/delete)**

4. **Unit tests for wrapper**
   - Add `backend/tests/unit/test_k8s_client.py`.
   - Use mocks to verify `create_namespaced_pod`/`delete_namespaced_pod` are called with correct args.
   - Cover config loading path (in-cluster vs kubeconfig) using mocks.
