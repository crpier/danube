# Plan: K3s Feasibility on Omarchy

## Goal
Answer whether installing K3s on Omarchy (Arch + Hyprland) is feasible for Danube development under the constraint of no root/system changes.

## Findings
- Danube docs assume root-level K3s installation via systemd and root-owned paths.
- K3s needs privileged operations (kernel networking, CNI, iptables/nftables) and writes to `/etc/rancher` and `/var/lib`.
- No Omarchy-specific requirements are documented; the setup is OS-level only.

## Recommended Response
- State that K3s on Omarchy is generally feasible, but **not** under “no root/system changes”.
- Point to Danube docs for the expected K3s installation flow if root becomes acceptable.
- Suggest alternatives: use a remote K3s/managed Kubernetes cluster for local dev without root changes.
